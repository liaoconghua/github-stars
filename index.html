诊断

三类重复：你的 star 里有大量「同一件事」

这才是「太多不知道干啥」的真正原因 —— 不是内容多，而是同质内容重复囤。同一生态位收 4-5 个，大脑自然无法为每个分配记忆位置。

Agent Skills 合集重复

  • superpowers、mattpocock/skills、ECC、agent-skills、khazix-skills 都在做同一件事：把工程方法论固化成技能包
  • 角色类又重复一层：agency-agents 与 agency-agents-zh 是同一项目的英文/中文版，awesome-claude-code 与 awesome-claude-code-subagents 是索引与其子集
  • 建议：方法论类留 superpowers + agent-skills，角色类留中文版

代码知识图谱四连收

  • graphify、codegraph、GitNexus、code-review-graph 是同一赛道的四个竞品，功能高度重叠
  • 你还有 repomix —— 它解决的是同一问题的轻量版（打包仓库喂 AI）
  • 建议：留 repomix（立刻能用）+ 1 个图谱工具实际测一次，其余取消

Agent 运行时五连收

  • deepseek-harness（你本机在跑 dsh）、Trellis、Codewhale、EvoFlow、homerail、Clutch 都是「agent 运行骨架」
  • homerail、Clutch、EvoFlow 星数都在 1000 以下，属于早期个人项目，成熟度未知
  • 建议：只保留你真正在用的 deepseek-harness，其余清掉

信息不足，无法判断

  • 有 4 个仓库完全没有描述，其中 3 个星数低于 100，光看名字猜不出用途
  • 这类是「当时觉得有用、现在完全失忆」的典型样本
  • 判断标准很简单：现在说不出它能解决你哪个具体问题 → 直接取消
